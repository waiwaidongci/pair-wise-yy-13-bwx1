# 纺织染整小样 · 回潮判级台

小样批次先回潮恒重、后判色差的工作台。React + Vite + TypeScript，纯前端 +
localStorage 持久化，刷新 / 重开页面后状态完全一致。

## 业务规则

1. **先回潮，后判级**
   - 环境门控：温度 20±2℃（18~22）、湿度 65±5%（60~70）须同时合格；
   - 相邻两次称量相对差须 ≤ 0.5%；
   - 至少 2 次称量且**末次称量合格**视为恒重。
   - 任一不满足，批次只能停在「待复测」，**色差判级入口关闭**。
2. **补测只追加，首个合格结果生效**
   - 称量记录只能追加，不能修改/删除；中间不合格记录保留留痕。
   - 判级成功后该克重周期结果即锁定，之后任何补测或再次提交都不能覆盖它。
3. **修改克重 = 旧判级立即失效**
   - 追加一个新的克重周期（世代），批次立即回到「待复测」重新走回潮流程；
   - 旧周期的称量记录与判级结果原样保留，可在详情底部展开查询，并在 Lab
     对比页以「已失效」灰行展示。
4. **单一事实来源**
   - 列表、批次详情、Lab 对比页全部由同一份状态经 `deriveBatch` 等纯函数派生，
     不存在各视图缓存不一致的可能。
5. 色差采用 CIE Lab ΔE*76，按变色灰卡 5 级 9 档评级（5/4-5/…/1）；
   ΔE 合格限值可在 Lab 页调整，仅作用于此后的新判级，历史结果保留判定时限值快照。

## 页面

- **批次判级台**：状态统计（待复测/可判级/合格/不合格/旧判级失效）、按客户与状态筛选、
  批次列表、批次详情（回潮称量录入、称量明细表、Lab 判级表单与锁定结果、改克重、历史周期）。
- **Lab 色差对比**：所有生效与已失效判级同表对照（标样/试样 Lab、ΔL/a/b、ΔE、灰卡、判定、限值快照），
  附不落库的 ΔE 速算器。

## 本地运行

```bash
npm install
npm run dev          # http://localhost:62012
```

其他命令：

```bash
npm test             # 领域规则 + store 集成测试（17 项，node:test，零额外依赖）
npm run typecheck
npm run build
```

测试通过 esbuild（vite 自带依赖）即时打包 `src/logic` 后由 Node 内置测试器运行，
覆盖门控边界、状态机、首个结果锁定、改克重世代归档、序列化（刷新）一致性、
列表与 Lab 同源口径等场景。

## 代码结构

```
src/logic/
  types.ts        领域模型（Batch / Era 世代 / WeighingRecord / GradingResult）
  rules.ts        纯函数：环境门控、恒重判定、ΔE76、灰卡、deriveBatch 状态派生
  store-core.ts   reducer（全部写操作均为追加）+ 种子数据，无 React 依赖
  store.tsx       StoreProvider + localStorage 持久化
src/components/    Bench / BatchList / BatchDetail / GradingForm / LabCompare 等
```
