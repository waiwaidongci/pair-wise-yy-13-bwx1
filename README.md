# 小样回潮判级台（纺织染整实验室）

纺织染整小样在判色差**之前必须先完成回潮平衡**的判级工作台。所有状态由不可变事件折叠得到，
刷新页面 / 多标签页之间状态一致（localStorage 持久化）。

## 业务规则

1. **先回潮后判色**：新批次处于「回潮中」，必须先做回潮称量。
2. **回潮门控**（任一不满足 → 批次只能「待复测」，判色差按钮锁定）：
   - 环境温度 20±2℃（18~22℃，含边界）
   - 环境湿度 65±5%RH（60~70%，含边界）
   - 相邻两次称量差 ≤ 0.5%（相对前一次称量，含边界）
3. **补测只追加**：称量记录只增不改；一旦出现首个合格的相邻称量对，门控即锚定生效，
   之后即使再补入不合格记录也不推翻。**仅首个合格结果可用于判级。**
4. **判级锁定**：一轮回潮只允许一次 Lab 判级（CIEDE2000 + ISO 105-A02 变色灰卡），
   结果不可更改；合格 ΔE 上限可在顶部设置。
5. **改克重即换代**：修改克重后旧判级**立即作废**，批次开新轮回潮并回到「待复测」；
   旧轮称量、旧判级全部保留，可在批次详情「履历」、Lab 对比（勾选显示作废）与判级台账中查询。

## 页面

- **批次列表**：新建批次、状态/门控/当前判级一览，点击行打开详情。
- **批次详情**（右侧常驻）：改克重、追加回潮称量（补测）、Lab 判级（带 ΔE00 实时预览）、
  各轮回潮称量与判级履历（含作废轮次）。
- **Lab 对比**：CIEDE2000 色差对比表（生效 / 已作废分开），及未判级批次的门控阻断原因。
- **判级台账**：所有判级结果（含已作废，仅追加不删除）与完整审计事件流水。

## 技术栈

React 19 + Vite + TypeScript。领域层为纯函数 + 事件溯源
（`src/domain/`：`engine.ts` 门控/命令/折叠，`color.ts` CIEDE2000/灰卡），
UI 层通过单一 store（`useSyncExternalStore`）订阅同一事件流，因此列表、Lab 对比、台账口径天然一致。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62012
```

## 测试

```bash
npm run typecheck  # TS 严格类型检查
npm test           # 领域规则单测（59 项：门控边界、补测锚定、改克重换代等）
npm run smoke      # jsdom + react-dom 真实渲染冒烟（操作流/三视图一致/刷新重放）
npm run build
```

首次打开会写入 7 个演示批次（回潮中、环境超限待复测、称量差超限待复测、补测合格待判级、
判级后改克重作废、合格后补测不推翻等场景），可用顶部「恢复演示数据 / 清空」重置。
